Network & model details

About 160 MB on the first visit, fetched from Hugging Face and stored in the browser cache. The demo works best on WebGPU and falls back to WASM when needed.

Model files are downloaded only after you press Download Model. This list then shows every request this page can see. Rows are not removed.

Transferred is transferSize, the bytes that crossed the network. Decoded is decodedBodySize. An HTTP-cached file can still have a decoded size and a small transfer.

Weight files live in Cache Storage (transformers-cache). A hit is not a network request, so it does not appear in the request list. The model file list asks that store directly. DevTools Disable cache does not bypass Cache Storage. To download the weights again, use DevTools > Application > Storage > Clear site data.

A later visit can show no weight traffic. The page and the ONNX Runtime WASM can still transfer (about 4.8 MB in a measured warm session). That figure is not the weights.

The service worker records fetches from this page and from workers it controls. The page and the speech worker also record resource timing and wrap fetch, XMLHttpRequest, WebSocket, and sendBeacon. One request seen more than once is one row. This view does not see DNS lookups, the parent page, other tabs, or a service worker registered outside this experiment.
